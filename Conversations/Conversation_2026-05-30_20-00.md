### 3. Four bugs reported via screenshot (all themes, all repos)

Screenshots showed Iris frontend with:
1. "Feature Inputs" and "Prediction Result" panel titles invisible in light mode
2. Current field value being reflected next to the field label (e.g. "SEPAL LENGTH CM  1")
3. Each field appearing twice in Input Summary (duplication)
4. No clear partition between rows in Input Summary

Root causes identified:
- No IDs on panel title divs → light-mode CSS could not target them
- `initSliders()` was appending a `.sv` span inside the `.inp-lbl` label to display the current value — user doesn't want value shown in the label
- `pForm.querySelectorAll('input')` was picking up hidden `<input type="range">` sliders (no `name` attr) alongside the real fields — each field appeared twice in the summary
- `el.previousElementSibling.textContent` included the `.sv` span text → label showed as e.g. "Sepal Length Cm1"
- Input Summary rendered each field as a separate div in a `display:grid;grid-template-columns:1fr 1fr` container — no row separators

- Deleted the block that created a `<span class="sv">` inside `.inp-lbl` to show the live value
- Deleted `var sv2` and all `if(sv2)sv2.textContent=...` calls from input, blur, and slider event handlers

#### Fix input collection in form submit (Iris, Titanic, Diabetes; Insurance already had this)
```javascript
// Before (broken — picks up sliders):
pForm.querySelectorAll('input').forEach(function(el) { ... })

// After (correct):
pForm.querySelectorAll('input, select').forEach(function(el) {
  if (el.type === 'range' || !el.name) return;
  ...
  var lblEl = el.previousElementSibling;
  var lbl = el.name;
  if (lblEl && lblEl.firstChild && lblEl.firstChild.nodeType === 3) {
    lbl = lblEl.firstChild.textContent.trim() || el.name;
  }
  ...
})
```

#### Input Summary partition — new `.sum-row` rendering (all 4 repos)
- Changed container from `display:grid;grid-template-columns:1fr 1fr;gap:6px` → `display:block`
- Changed rendering loop from one div-per-field to one div-per-pair:
  ```javascript
  for (var _si = 0; _si < summary.length; _si += 2) {
    var _row = document.createElement('div');
    _row.className = 'sum-row';
    var _L = summary[_si], _R = _si + 1 < summary.length ? summary[_si + 1] : null;
    _row.innerHTML =
      '<span class="sum-lbl">' + _L[0] + '</span>' +
      '<span class="sum-val">' + _L[1] + '</span>' +
      (_R ? '<span class="sum-lbl">' + _R[0] + '</span><span class="sum-val" style="padding-right:0">' + _R[1] + '</span>' : '');
    inputSum.appendChild(_row);
  }
  ```
