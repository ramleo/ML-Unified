## User Requests This Session

### 1. Explain inline `style="color:#fff"` vs CSS variable override
**Question:** What does "text inside inline style='color:#fff' spans … handled via targeted !important rules" mean?

**Answer:** Inline `style="color:#fff"` has the highest CSS specificity and beats any class rule. Adding `!important` to a targeted `[data-theme="light"] #id { color: … !important; }` rule forces it to win even against inline styles. Elements using `var(--txt-primary)` switch cleanly; elements with hardcoded inline colors need the `!important` workaround.

### 5. Four light-mode bugs reported via screenshots

#### Bug 1 — Double tab to move to next field (light mode only)
**Root cause:** `<input type="range">` sliders injected by `initSliders()` were in the tab order; browser autocomplete dropdowns also intercepted the first Tab press in light mode (form looks native to browser).

**Fix (commit `576fc02`):**
- `sl.tabIndex = -1` on every dynamically created slider → removed from keyboard tab order
- `autocomplete="off"` on `<form id="pForm">` → prevents browser dropdown intercepting Tab

#### Bug 2 — Wavy/chevron pattern on `<select>` in light mode
**Root cause:** `[data-theme="light"] select.inp` only overrode `background-image` but left `background-color` as `var(--inp-bg)` = `rgba(255,255,255,.75)` (semi-transparent). The browser's native select texture bled through the transparent background, creating the wavy pattern.

**Fix (commit `576fc02`):**
```css
[data-theme="light"] select.inp {
  background-color: #fff;
  background-image: url("...light chevron...");
  background-repeat: no-repeat;
  background-position: right 12px center;
}
```

#### Bug 3 — Remove "Range" text and "Near/Above/Below Average" badge
**Request:** "Please remove range and average info, it is not required in prediction result."

**Fix (commit `576fc02`):**
- Removed `#resConf`, `#benchmarkBadge`, `#benchmarkTipWrap` from HTML entirely
- Removed JS that set "Range: X – Y (±1σ)" text on `resConf`
- Removed JS that populated benchmark badge and tooltip
- Removed `/metrics` benchmark tooltip code block
- CI visual bar/dot track is still present — shows prediction position within range without any text label

#### Bug 4 — "Feature Inputs" and "Prediction Result" titles invisible in light mode
**Root cause:** Both title divs had inline `style="color:#fff"` which beats `[data-theme="light"] .glass { color: #0a1a35; }` (no `!important`).

**Fix (commit `576fc02`):**
- Added `id="formPanelTitle"` and `id="resPanelTitle"` to both title divs
- Added CSS:
```css
[data-theme="light"] #formPanelTitle,
[data-theme="light"] #resPanelTitle { color: #0a1a35 !important; }
```
