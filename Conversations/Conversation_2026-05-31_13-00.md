### 5. Fix non-clickable TOC links (the actual root cause)

**Problem:** Clicking TOC entries in the PDF did nothing. User was frustrated that previous attempts didn't work.

**Root cause (diagnosed by inspecting LaTeX intermediate):**
- TOC links had: `#1-what-is-this-platform`, `#2-platform-architecture`, `#91-what-if-sliders`, etc.
- Pandoc-generated section labels were: `what-is-this-platform`, `platform-architecture`, `what-if-sliders`, etc.
- **Pandoc strips leading numbers from heading IDs** (rule: "remove everything up to the first letter")
- Em-dashes in headings collapse to single hyphens, not double
- Sub-section numbers like `9.1` are also stripped

**Scale of breakage:** ~25 broken anchors across the entire TOC, plus one extra broken link in the body text (§13).

**Fix method:**
1. Generated LaTeX intermediate with `pandoc -t latex`
2. Extracted all real labels: `grep '\\label{' | sed ...`
3. Extracted all link targets: `grep 'hyperref\[' | grep -oP ...`
4. Diffed them: `comm -23 links.txt labels.txt` → showed every broken link
5. Rewrote the entire TOC section with correct anchors
6. Re-ran diff → zero broken links
7. Rebuilt PDF

**Example fixes:**

|---|---|
| `#1-what-is-this-platform` | `#what-is-this-platform` |
| `#3-quick-start--three-ways-to-begin` | `#quick-start-three-ways-to-begin` |
| `#91-what-if-sliders` | `#what-if-sliders` |
| `#8-the-frontend-indexhtml` | `#the-frontend-index.html` |
| `#dark--light-theme-toggle` | `#dark-light-theme-toggle` |

## Key Technical Facts Established This Session

- **Pandoc heading ID rule:** IDs are generated by lowercasing, replacing spaces with hyphens, removing punctuation, then **removing everything up to the first letter** — so leading numbers like `1.`, `9.1`, `20-` are all stripped.
- **Em-dash in headings** (`—`) collapses to nothing or a single hyphen in the ID, not `--`.
- **`\PassOptionsToPackage{...}{hyperref}`** must appear before `\usepackage{hyperref}` — works correctly in pandoc's `-H` header injection since pandoc loads hyperref later in its template.
- **`docker info`** is the correct way to test if the Docker daemon is reachable (returns non-zero if not running).
- **`--toc` + manual TOC** = two TOCs in the PDF. Always use one or the other, not both.
