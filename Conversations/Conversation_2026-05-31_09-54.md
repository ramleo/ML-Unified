## User Requests This Session

### 1. Diagnose `lightgbm` build failure when running `bootstrap.py`

**Error:**
```
ninja: error: '/opt/homebrew/opt/libomp/lib/libomp.dylib', needed by 'lib_lightgbm.so',
missing and no known rule to make it
```

**Root cause:** System Python is 3.14. LightGBM has no pre-built wheel for Python 3.14 yet — pip falls back to compiling from source, which requires `libomp` (OpenMP). `libomp` was not installed on this Mac.

**Immediate fix:** `brew install libomp`

**Longer-term fix:** Dockerize with Python 3.11, which has pre-built wheels — no compilation, no `libomp` needed.

### 8. Explain `./run.sh` vs `./start.sh`

| | `./run.sh` | `./start.sh` |
|---|---|---|
| Runs inside | Docker container | Your Mac |
| Python version | 3.11 (pinned) | System Python (was 3.14 — caused errors) |
| lightgbm/xgboost/catboost | Pre-installed in image | Installed fresh (needs `libomp` on macOS) |
| Works on Windows | Yes (Docker Desktop) | No |
| First run | ~5 min (image build, cached after) | Faster |
| Isolated from Mac | Fully | No |

**Recommendation:** Use `./run.sh` going forward.
