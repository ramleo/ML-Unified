## User Requests This Session

### 1. Fix auto-predict on every input event
**Problem:** Each slider drag or number key press triggered a debounced `/predict` call — wasteful and irritating.

**Fix applied (all 4 repos):**
- Removed `debouncedPredict(420)` from `inp.addEventListener('input')`
- Removed `debouncedPredict(300)` from `sl.addEventListener('input')`
- Sliders now only sync the number input value
- Predict fires **only on button click**
- Commits: Insurance `da9f2f6`, Iris `da6d7e7`, Titanic `05a6724`, Diabetes `a6fa6f1`

### 2. Proper range enforcement on number inputs
**Problem:** `min`/`max`/`step` were set on the slider element but not on `<input type="number">`, so the browser had no bounds to enforce. Users could type out-of-range values freely.

**Fix applied (all 4 repos):**
- `inp.min`, `inp.max`, `inp.step` now set from `/ranges` in `initSliders()`
- Blur handler clamps any out-of-range value back to the nearest valid bound
- Placeholder shows valid range, e.g. "18 – 85"
- If `max` is null (e.g. Annual Income), no `inp.max` is set and no upper clamping happens

### 3. Remove upper limit on Annual Income
**Problem:** Annual Income was capped at $157,493 (dataset max). High earners get their value clamped, which is wrong.

**Fix applied (Insurance only — only repo with feature_ranges.json):**
- `feature_ranges.json`: Annual Income `max` → `null`, added `slider_max: 500000`
- JS `initSliders`: `hasMax` flag — when `null`, skips `inp.max` and shows `"0+  (no upper limit)"` as placeholder
- Slider uses `slider_max` (500,000) as initial visual range; expands 1.5× as user types higher
- No blur clamping on the upper end for uncapped fields
- Commit: Insurance `15d88c7`

### 4. Use domain-informed bounds for all numeric fields
**Research:** Used web search to find realistic insurance-domain bounds (FICO spec, NAIC, ACA guidelines).

Updated bounds in `feature_ranges.json`:

| Field | Old max | New max | Source |
|---|---|---|---|
| Age | 66 | 85 | NAIC — life insurance caps at 75–90 |
| Annual Income | 157,493 | null (no cap) | ACA/industry — no upper limit |
| Number of Dependents | 4 | 10 | ACA — no hard cap; 0–10 practical |
| Health Score | 58 | 100 | Dataset uses 0–100 scale |
| Previous Claims | 8 | 10 | 5–7 year lookback; 0–10 covers all |
| Vehicle Age | 20 | 25 | Classic car threshold = 25 years |
| Credit Score | 876 | 850 | Standard FICO range: 300–850 |
| Insurance Duration | 9 | 40 | Long-term life: up to 40 years |
