### 2. Input Summary — vertical divider (correct fix)
User clarified: one straight line from top to bottom, not a line on each row.

**Root cause of wrong approach:** CSS `border-left` on individual spans only draws for the height of that row element, not the full container height.

**Correct approach:** Changed the rendering to a proper two-column layout with a single shared divider element:

```
[.sum-col left]  [.sum-divider]  [.sum-col right]
```

- JS now builds two separate `div.sum-col` elements (left = odd-indexed fields, right = even-indexed fields)
- A single `div.sum-divider` sits between them — `1px` wide, `align-self:stretch` so it fills the full container height
- `#inputSummary` becomes `display:flex; align-items:stretch`
- Removed all `.sum-val + .sum-lbl` border hacks

**CSS added/changed:**
```css
.sum-lbl { flex:1; font-size:.84rem; color:rgba(255,255,255,.35); min-width:0; }
.sum-val { flex:0 0 auto; min-width:48px; text-align:right; font-weight:500; font-size:.84rem; color:#fff; }
.sum-col { flex:1; min-width:0; }
.sum-divider { width:1px; background:rgba(255,255,255,.22); margin:0 14px; flex-shrink:0; align-self:stretch; }
#inputSummary { display:flex; align-items:stretch; }
[data-theme="light"] .sum-divider { background: rgba(41,121,255,.2) !important; }
```
