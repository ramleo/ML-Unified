### 3. ID Column Removal

**User request:** Remove ID columns — they add no value for users.

**What changed:**

- builds_bootstrap (`f4da884`): `_is_id_col()` detects ID cols, excludes from InputData, `_ID_COLS` list injects NaN at predict time
- ML-Iris (`68e2b53`): `Id` removed from InputData; `_ID_COLS = ["Id"]`
- ML-Titanic (`da153bd`): `PassengerId` removed from InputData; `_ID_COLS = ["PassengerId"]`
- ML-Diabetes: No ID column — no change
- ML-Insurance: `id` was dropped at retrain time — not in pipeline at all

**Why NaN injection (not full removal):** Pipeline was trained with ID columns. ColumnTransformer expects those names. Removing from DataFrame causes KeyError. NaN is injected instead — SimpleImputer fills with training median. Predictions are identical.

### 7. What-if Sliders + Prediction Comparison Table

**User request:** Implement sliders and comparison table.

#### Sliders

- Every numeric input gets an `<input type="range">` injected below it via JS
- Slider and number input stay in sync bidirectionally
- Changing slider fires debounced `/predict` (300–420ms) — no button click needed
- Ranges loaded from `GET /ranges` endpoint (reads `models/feature_ranges.json`)
- Auto-range: if no stored ranges, slider expands as user types (max = value × 2)

**Insurance slider ranges (from dataset):**

| Field | Min | Max | Step |
|---|---|---|---|
| Age | 18 | 66.3 | 1 |
| Annual Income | 17 | 157,493 | 1000 |
| Number of Dependents | 0 | 4.2 | 1 |
| Health Score | 2.46 | 58.63 | 0.1 |
| Previous Claims | 0 | 8.4 | 1 |
| Vehicle Age | 0 | 19.95 | 1 |
| Credit Score | 300 | 876 | 1 |
| Insurance Duration | 1 | 9.4 | 1 |

#### Comparison Table

- JS array `_history` accumulates every prediction
- Table appears below main grid once ≥ 2 predictions exist
- Columns: # | Key fields | Prediction | Range (regression) | vs Avg (regression) / Confidence (classification)
- Changed cells vs previous run highlighted white + bold
- "Clear" button resets (session only, no backend)

**Architecture:**
```
Page load → fetch('/ranges') → initSliders(ranges)
User drags slider → debounce 300ms → POST /predict → showResult(data) → addToHistory(data)
                                                                        └─ renderHistory() if ≥2 runs
```
